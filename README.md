## Hướng dẫn Gia nhập CLB

Thành viên mới vui lòng thực hiện tuần tự các bước sau để thiết lập môi trường làm việc:

1. **Clone repository chính thức của CLB về máy tính:**
   ```bash
   git clone https://github.com
   ```
2. **Tạo nhánh làm việc riêng mang tên cá nhân của bạn:**
   ```bash
   git checkout -b feature/gia-nhap-[ho-ten-khong-dau]
   ```
3. **Thêm thông tin cá nhân vào thư mục thành viên và lưu thay đổi:**
   ```bash
   git add .
   git commit -m "chore: add new member info"
   ```
4. **Đẩy nhánh lên hệ thống và tạo Pull Request (PR):**
   ```bash
   git push origin feature/gia-nhap-[ho-ten-khong-dau]
   ```
